# Roadmap

The canonical, versioned roadmap lives at the repository root:
[`ROADMAP.md`](../ROADMAP.md).

This page exists for consistency with the documentation suite. It tracks the same roadmap and
will be kept in sync on each release.

- **v1.0 — Foundation** (released): 14-phase pipeline, discovery + OSPI scoring, acquisition,
  audit, modernization, testing, docs, quality certificate, portfolio.
- **v1.1 — Autonomous Depth**: real SAST, dependency scanning, GraphQL search, live push/PR.
- **v1.2 — Community Intelligence**: active PR-review polling and automated maintainer responses.
- **v2.0 — Enterprise Scale**: parallel pipelines, database-backed memory, CTO dashboard.
- **v2.1 — Full Autonomy**: self-hosted runners, container scanning, LLM adapters.
